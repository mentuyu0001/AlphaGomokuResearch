# AlphaZeroベース 五目並べAI

深層強化学習（Deep Reinforcement Learning）の学習用プロジェクトとして開発した、AlphaZeroベースの五目並べAIです。

ゲームAIの研究へ転向するにあたり、基礎技術の習得および、ニューラルネットワークと探索アルゴリズムの挙動を確認するために実装しました。

## 概要

DeepMind社のAlphaZeroアルゴリズムを参考に、ゼロからルールを学習する五目並べAIです。
棋譜データを用いた教師あり学習は行わず、自己対局（Self-Play）のみで強化を行いました。

### 背景
以前は画像分類（Image Classification）の研究を行っており、その際に扱っていたCNNやResNetの知識をゲームAI分野へ応用する目的で制作しました。
画像認識技術が盤面評価にどのように機能するか、実地で確認することを重視しています。

## 実装とルールの工夫

AlphaZeroのアルゴリズムを忠実に再現しつつ、学習効率とゲームバランスの観点で以下の調整を行っています。

* **アルゴリズム**: ResNetを用いたニューラルネットワークと、モンテカルロ木探索（MCTS）の組み合わせ。
* **学習率の調整**: 学習の進行度に応じて学習率（Learning Rate）を減衰させるスケジューリングを導入。
* **初期配置のランダム化**:
  単純な五目並べにおける先手必勝を防ぐため、**「先手（黒）1石」「後手（白）4石」がランダムに配置された状態**から対局を開始するルールを採用しています。
* **ルール詳細**: 禁じ手なし。

## 学習環境と結果

個人のPC環境にて学習を行いました。

* **GPU**: NVIDIA GeForce RTX 4080
* **学習期間**: 約1日 (24時間)

### 結果
1日程度の学習ですが、「4つ石が並んだら勝ちに行く」「相手のリーチ（3連・4連）を防ぐ」といった基本的な戦術を獲得している様子が確認できました。
AlphaZero本来の性能を引き出すにはさらなる計算資源が必要ですが、基礎的な学習動作と強化学習のパイプラインは正常に動作しています。
